01 / Overview

What KLEAN does

KLEAN is a browser extension designed to reduce ads, trackers, and unwanted web clutter. Core protection works without requiring an account.

02 / Data Practices

What data KLEAN handles

KLEAN is designed to minimize data handling. The extension does not intentionally collect the categories of personal or browsing information listed below for storage or profiling.

  • Personally identifiable information
  • Health information
  • Financial or payment information
  • Authentication information
  • Personal communications
  • Location information
  • Browsing history
  • User activity
  • Website content

KLEAN DOES NOT

  • Does not require an account for core functionality.
  • Does not sell user data.
  • Does not intentionally collect personal information.
  • Does not intentionally collect browsing history.
  • Does not intentionally collect website content for storage or profiling.
  • Does not use browsing data for advertising profiles.
  • Does not use user data for creditworthiness or lending decisions.
  • Does not intentionally execute remote extension code.

03 / Chrome Permissions

Why Chrome permissions are needed

KLEAN requests only the permissions needed to apply its filtering, respond to extension controls, and retain local preferences and aggregate counters.

declarativeNetRequest

Used to evaluate and block network requests according to KLEAN’s bundled filtering rules.

activeTab

Allows KLEAN to interact with the currently active webpage when you invoke extension controls.

storage

Stores extension preferences, site settings, and local aggregate blocking statistics.

webNavigation

Allows KLEAN to respond to webpage navigation events so filtering and site-specific behavior can update appropriately.

HTTP/HTTPS host permissions

Required so KLEAN can apply webpage filtering, cosmetic filtering, and site controls across websites.

04 / Local Storage

Local storage

KLEAN stores extension settings and aggregate blocking information locally so your preferences can persist between browser sessions.

  • User protection settings
  • Site-specific preferences
  • Blocking counters and aggregate statistics
  • Extension configuration

05 / Filtering

Filtering

KLEAN evaluates network requests against its bundled filtering rules to identify and block supported advertising and tracking requests.

Filtering and site controls are applied locally by the extension. KLEAN does not intentionally collect website content for storage or profiling.

06 / Third-Party Resources

Third-party resources

The website may load standard third-party web resources for presentation and icons. These website resources are separate from KLEAN's core extension filtering logic.

KLEAN does not intentionally execute remote extension code. Its extension behavior is based on code and filtering rules included with the extension.

07 / Security

Security

KLEAN is designed to limit data collection and keep supported settings and aggregate statistics in local browser storage. No security system can guarantee absolute security.

08 / Changes

Changes to this policy

If KLEAN's data practices or relevant permissions change, this policy may be updated to describe those changes.
